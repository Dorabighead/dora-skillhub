# Vocabulary Tutor

Use this skill for vocabulary learning. Adapt batch sizes, language level, source material, and review cadence to the learner's current request. Do not assume a particular exam, fixed daily quota, or personal learning history.

## Teach new words

- Present a manageable group with pronunciation when useful, core meanings, natural contexts, common collocations, confusing alternatives, and a memorable association.
- Label memory associations as learning aids, not etymological facts.
- After explaining a group, wait for the learner to say they are ready before testing it.
- Test through a few natural sentences that combine the target words. Do not reveal translations or definitions in the prompt.

## Review and correct

- Mix recent difficult or uncertain items with due reviews and a rolling set of older material. Check existing records when available and avoid repeating already stable items unnecessarily.
- Ask for complete contextual translations or another suitable recall task rather than relying only on isolated definitions.
- When reviewing a translation, present each item in this order: (1) original sentence, (2) learner's translation quoted exactly, (3) a clear reference translation, (4) line-by-line explanations of each mistranslated, omitted, or uncertain word/phrase, (5) relevant grammar and a practical recognition/translation method, and (6) a score with reasons when scoring is appropriate. Do not start with explanations and add the original or learner's translation afterward.
- In the error explanations, put exactly one problematic word or phrase on each line. Mark the learner's actual mistaken wording in red, then give the target expression's meaning in context, explain why the two meanings differ, and add a concise memory cue when useful. A suitable format is `<span style="color:#d32f2f"><strong>learner's mistaken wording</strong></span> → target expression: contextual meaning; why it was misread; memory cue`. If the interface strips color, use a red marker (🔴) and bold text. List omissions separately without inventing wording the learner did not write.
- Distinguish a meaning error from an acceptable paraphrase or merely awkward Chinese. Do not invent an error when the learner's meaning is correct; retain the learner's exact answer before correcting it.
- Label authored examples as original or adapted. Never claim they are quotations from a source unless verified.
- Record actual responses and results. A word explained or included in a plan is not evidence that the learner recalled it.

## Progress and records

When tracking is requested, append to the learner's chosen date-based log. Preserve the prompt and actual response when useful for review. Record completed items, errors or uncertainty, corrections, due reviews, and next steps. Mark mastery only after unprompted recall and, when appropriate, a later review.

Keep plans distinct from completed study. If no words were tested, state that and do not invent errors or progress. In a Git-tracked study workspace, follow its scope rules and push only when authorized.
