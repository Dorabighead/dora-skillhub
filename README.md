## 📌 项目简介

收录考研学习辅导与软件开发工作流，支持在适用的对话或工程任务中按需载入。

## 🏗️ 系统架构

- 每个学习技能以 `SKILL.md` 定义适用场景和步骤。
- 软件开发工作流以独立文档组织，使用时按当前仓库和任务的说明执行。

## 📁 项目结构

| 路径 | 用途 |
| --- | --- |
| [`learning`](learning) | 数学、政治、专业课和英语词汇技能 |
| [`software-development`](software-development) | 软件开发工作流与使用入口 |

## 🚀 如何启动

打开需要的技能目录查看 `SKILL.md`，再按工具的技能安装方式复制该目录，或直接在当前项目按对应工作流使用。

## Learning

- [Mathematics tutor](learning/math-tutor/SKILL.md): review problems and written work with evidence-based explanations.
- [Politics tutor](learning/politics-tutor/SKILL.md): verify sources, explain concepts, analyze past questions, and support recall practice.
- [Professional-course tutor](learning/professional-course-tutor/SKILL.md): teach course material, assess independent work, and plan review.
- [Vocabulary tutor](learning/vocabulary-tutor/SKILL.md): teach and review vocabulary through contextual exercises and evidence-based progress tracking.

## Software development

- [Development workflow](software-development/README.md): a general workflow for understanding, changing, reviewing, and validating software projects.

## Privacy

The files are generalized for public reuse. They contain no personal study records, private workspace paths, account details, or individual exam history.
